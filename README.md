# davidzhangsan.github.io

Personal academic website, originally based on [Jon Barron's template](https://github.com/jonbarron/jonbarron_website).

Edit the content in `index.html`, the shared styles in `stylesheet.css`, and the lightweight interactions in `site.js`. The profile photo is `images/profile.jpg`. No build step or dependencies are required.

Preview locally with `python3 -m http.server 8000`, then open `http://localhost:8000`.

The soccer and Shanghai Port pages keep a shuffled photo sequence in local storage. Their photo lists and descriptions live in the JavaScript file beside each page.
